Question 2 – Excel Functions
1. SUM
The SUM function is used to calculate the total of numbers.
Example: =SUM(B2:B10)

2. AVERAGE
The AVERAGE function calculates the average value of selected numbers.
Example: =AVERAGE(B2:B10)

3. IF
The IF function checks a condition and returns one value if it is true and another if it is false.
Example: =IF(B2>=50,"Pass","Fail")

4. COUNTIF
COUNTIF counts the number of cells that meet a specific condition.
Example: =COUNTIF(C2:C20,"Completed")

5. XLOOKUP or VLOOKUP
These functions are used to search for specific information in a table and return the matching result.

Example: =XLOOKUP(A2,E2:E10,F2:F10,"Not Found")
Bonus – Pivot Table

A Pivot Table is used to summarise and analyse large amounts of data. It helps identify total sales, product performance, category-wise revenue, and monthly trends without manually calculating everything.

Question 6 – Competitor Price Analysis
Given information:
- Selling price = $149.95
- Product cost = $110
- Payment cost = 3%
- Shipping cost = $8
- Marketing cost = $10
1. Gross dollar profit
Gross Profit = Selling Price − Product Cost
= $149.95 − $110
= $39.95

2. Gross profit margin
Gross Profit Margin = (Gross Profit / Selling Price) × 100
= (39.95 / 149.95) × 100
= 26.64%

3. Approximate profit after listed costs
Payment cost = 3% of $149.95 = $4.50
Net Profit = Selling Price − Product Cost − Payment Cost − Shipping Cost − Marketing Cost
= $149.95 − $110 − $4.50 − $8 − $10
= $17.45

4. Approximate net margin
Net Margin = (Net Profit / Selling Price) × 100
= (17.45 / 149.95) × 100
= 11.64%

5. Would you recommend selling this product?
Yes, I would recommend selling this product on a trial basis because it generates an estimated profit of $17.45 per order after the listed costs. However, the net profit margin is only 11.64%. Before launching, I would also check product demand, return rates, packaging costs, and other operating expenses to ensure the product remains profitable.
